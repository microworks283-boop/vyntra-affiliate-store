# VYNTRA — Affiliate Storefront + Android-ready PWA

A responsive React storefront with a small Express product API, VYNTRA logo, category/store filters, product search, saved-item hearts, affiliate disclosure, and installable PWA support. The same frontend can be wrapped as an Android app with Capacitor.

## Important before launch
- This is a working starter project, not a live deployed website or a Play Store-published app.
- Product entries use sample data and generic retailer home-page links. Replace them with your **approved affiliate URLs / deep links** before publishing. Do not assume these sample links earn commission.
- Confirm each affiliate programme permits your promotional method, product images, price display, tracking and app usage. Use images and product data you are authorized to use. Prices/availability need a reliable update process.
- Add your legal business/contact details, privacy/cookie policy and any disclosures required by the relevant programmes and Indian law. Keep the affiliate disclosure visible.
- The server is a basic product API, not a secure admin system, checkout, inventory system or order processor. Purchases happen on retailer websites.

## Requirements
Install Node.js LTS (Node 20 or 22 recommended) and Git if desired. Windows PowerShell / Command Prompt instructions below.

## Run locally on Windows
1. Extract `VYNTRA-Affiliate-Store.zip`.
2. Open Command Prompt in the extracted `VYNTRA-Affiliate-Store` folder.
3. Run `npm install`.
4. Run `npm run install:all`.
5. Run `npm run dev`.
6. Open `http://localhost:5173`.
   - Frontend: `http://localhost:5173`
   - API health: `http://localhost:4000/api/health`
   - Product API: `http://localhost:4000/api/products`
7. To stop, press `Ctrl+C`.

If Windows says `npm` is not recognized, install Node.js LTS, close and reopen the terminal, then run `node -v` and `npm -v`.

## Add your affiliate links / products
1. Open `server/products.json` in VS Code or Notepad.
2. Each item has `title`, `category`, `store`, `price`, `oldPrice`, `tag`, `image`, `link`, and `description`.
3. Replace `link` with the actual tracked URL generated by the relevant affiliate dashboard. Use the retailer's approved deep-link generator where required.
4. Use `image` URLs you have permission to use. Keep JSON valid: double quotes around keys/strings, no trailing comma.
5. Add a product by copying one object and giving it a unique `id`.
6. Restart the server if needed.

The store filters expect `Amazon`, `Flipkart`, `Myntra`, `Meesho`, and `AJIO` spelling. Use the category names shown on the website.

## Production build
From the project root:
1. Run `npm run build`.
2. For a simple single-server deployment, run `npm start` and host the `client/dist` build with the Express server. Set `PORT` if your hosting provider requires it.
3. Deploy to a Node.js host that supports your chosen plan. Add HTTPS and a custom domain. Test all affiliate links and mobile layouts after deployment.
4. For separate frontend/backend hosting, configure the frontend API URL in your deployment architecture; this starter is set up for local same-origin/proxy usage and needs adjustment for a separate host.

## Android app options

### Option A — install the PWA (fastest)
1. Deploy the website to an HTTPS domain.
2. Open the site in Chrome on Android.
3. Use Chrome menu → **Install app** / **Add to Home screen**.
4. The app opens in a standalone window. PWA installation prompts vary by device/browser.

### Option B — build a native Android wrapper with Capacitor
You need Android Studio, Android SDK, and a JDK supported by the installed Android Gradle Plugin (use the version required by the current Capacitor/Android Studio documentation; JDK 17 is commonly used for modern Android builds).

1. In the root folder run:
   `npm install`
   `npm --prefix client install`
   `npm --prefix client install @capacitor/core @capacitor/cli`
2. From `client` run:
   `npx cap init VYNTRA com.vyntra.shop --web-dir dist`
3. Build the site:
   `npm run build --prefix client`
4. Add Android:
   `cd client`
   `npx cap add android`
   `npx cap sync android`
   `npx cap open android`
5. In Android Studio, wait for Gradle sync, choose an emulator or connect an Android phone with developer options/USB debugging enabled, then press Run.
6. For a release, create a signed Android App Bundle (AAB) in Android Studio and follow current Google Play Console requirements.

If `npx cap add android` reports that Android already exists, continue with `npx cap sync android`. Capacitor commands and requirements may change; consult official Capacitor documentation if the CLI asks for a newer setup step.

**Brand assets:** the supplied logo is copied to `client/public/assets/vyntra-logo.png` when available. If it is missing, copy your logo there using that exact filename.

## Authentication update

New accounts require email verification by a 6-digit OTP before activation. Signup collects a name, email, and password (minimum 8 characters); the password is hashed with bcryptjs. Returning users log in using **email + password only** (no OTP at login). Configure Gmail SMTP using `server/.env` copied from `server/.env.example`. Read `README-V2.md` for setup and production security notes.

VYNTRA's purpose is to bring product discovery across participating shopping platforms into one place; customers complete checkout on the retailer's website.
